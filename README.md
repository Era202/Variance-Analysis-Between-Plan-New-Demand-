# APS Planning & BOM Analysis Tool

## 📌 Overview

This tool is designed to analyze production plans, BOM explosion, and material requirements using Python and Streamlit.

## 🚀 Features

* BOM explosion with accurate quantity aggregation
* MRP Controller filtering
* Stock coverage analysis
* Export results to Excel
* Demand vs supply gap analysis

## 📊 Input Files

* Production Plan
* BOM Structure
* Stock Data

## ▶️ How to Run

1. Upload required Excel files
2. Select MRP Controller (optional)
3. Run analysis
4. Export results

## ⚠️ Notes

* Ensure consistent column names across all sheets
* Data should be cleaned before upload
